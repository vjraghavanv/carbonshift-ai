Title (max 255 characters):
CarbonShift AI: letting Strands Decider 2B pick when and where cloud jobs run to cut carbon

Description (max 512 characters):
CarbonShift AI is a Strands Agents app on Amazon Bedrock AgentCore Runtime that schedules flexible cloud workloads for lower carbon without missing deadlines. Hard constraints run in code; Strands Decider 2B makes the carbon-versus-deadline trade-off as a typed choice among feasible candidates. On a held-out test set it matched a Bedrock LLM at 100% accuracy with a steady 3.3s decision and far tighter latency, for a fraction of a cent per 1,000 decisions.
